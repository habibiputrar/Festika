# Aset dan Atribusi

## Logo dan identitas

`public/branding/Logo_Festika-04.webp` merupakan identitas FESTIKA. Logo HMIF UNAND, BEMKM FTI, dan Universitas Andalas digunakan untuk mempertahankan konteks tampilan proyek. Hak logo dan nama institusi tetap berada pada pemilik masing-masing.

MIT License repository berlaku pada kode aplikasi, bukan pemberian hak merek atau lisensi baru atas logo institusi. Jika proyek diadaptasi untuk acara atau organisasi lain, ganti logo, nama, kredit, alamat, dan materi terkait.

## Galeri dan dokumen contoh

`public/branding/demo/` berisi enam ilustrasi SVG serta dua PDF contoh. Berkas tersebut dibuat oleh `scripts/create-demo-assets.mjs` dan diberi penanda data contoh. Ilustrasi tidak mewakili foto kegiatan atau hasil kompetisi sebenarnya.

Album foto dan panduan produksi tidak disertakan. Untuk mengganti galeri dalam sesi demo, unggah file melalui Media dan pilih pada Konten Website. Untuk mengubah aset bawaan repository, tambahkan berkas publik yang sesuai dan perbarui seed.

## Font

Plus Jakarta Sans didistribusikan melalui paket `@fontsource-variable/plus-jakarta-sans`. Font dibundel secara lokal, sehingga browser tidak perlu menghubungi Google Fonts. Lisensi font disertakan oleh paket dan mengikuti SIL Open Font License.

## Ikon

Ikon berasal dari Lucide melalui paket `lucide-react`. Lisensi dependency tetap mengikuti paket asal.
